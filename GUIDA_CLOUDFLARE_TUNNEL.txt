================================================================================
URIELSCAN - GUIDA OPERATIVA CLOUDFLARE TUNNEL (PIANO GRATUITO)
Scenario: Server Ubuntu in VLAN dedicata/isolata + Remote Probe presso clienti
================================================================================

1. PERCHE' QUESTA ARCHITETTURA E' SICURA
--------------------------------------------------------------------------------
- UrielScan ascolta SOLO in locale su 127.0.0.1:8000 dentro il server Ubuntu.
- Il demone "cloudflared" apre SOLO connessioni in USCITA verso Cloudflare (443).
- NON devi aprire nessuna porta in ingresso sul firewall aziendale verso la VLAN.
- Le sonde remote presso i clienti (urielscan_probe.py) comunicano in HTTPS
  verso il tuo dominio pubblico (es. https://urielscan.urielsec.com).
- Funziona interamente con il piano GRATUITO di Cloudflare + Cloudflare Zero Trust.

2. PREREQUISITI
--------------------------------------------------------------------------------
1) Un dominio di tua proprietà (es. urielsec.com) gestito sui DNS di Cloudflare
   (piano Free).
2) Un server Ubuntu nella VLAN dedicata con Python 3.10+, Nmap (opzionale sul
   server centrale se usi solo sonde remote) e UrielScan installato.

3. AVVIO URIELSCAN COME SERVIZIO SYSTEMD SU UBUNTU
--------------------------------------------------------------------------------
Crea il file /etc/systemd/system/urielscan.service (adatta percorsi e utente):

  [Unit]
  Description=UrielScan Purple Team Platform
  After=network.target

  [Service]
  User=urielscan
  WorkingDirectory=/opt/UrielScan
  ExecStart=/usr/bin/python3 /opt/UrielScan/run.py --no-browser --host 127.0.0.1 --port 8000
  Restart=always
  RestartSec=5

  [Install]
  WantedBy=multi-user.target

Abilita e avvia il servizio:
  sudo systemctl daemon-reload
  sudo systemctl enable --now urielscan
  sudo systemctl status urielscan

4. CREAZIONE DEL TUNNEL SU CLOUDFLARE ZERO TRUST (WEB DASHBOARD)
--------------------------------------------------------------------------------
1) Accedi a https://one.dash.cloudflare.com (piano Free).
2) Vai su: Networks -> Tunnels -> Create a tunnel.
3) Scegli il connettore: Cloudflared -> Next.
4) Assegna un nome al tunnel (es. "urielscan-msp") -> Save tunnel.
5) Nella schermata di installazione scegli "Debian / Ubuntu" (64-bit) e copia
   il comando con il token:
     sudo cloudflared service install <TUO_TUNNEL_TOKEN>

5. INSTALLAZIONE CLOUDFLARED SUL SERVER UBUNTU
--------------------------------------------------------------------------------
Sul server Ubuntu nella VLAN isolata esegui:

  curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
  echo "deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main" | sudo tee /etc/apt/sources.list.d/cloudflared.list
  sudo apt-get update && sudo apt-get install -y cloudflared

Poi collega e avvia il tunnel usando il tuo token:
  sudo cloudflared service install <TUO_TUNNEL_TOKEN>
  sudo systemctl status cloudflared

6. PUBBLICAZIONE DELL'HOSTNAME (PUBLIC HOSTNAME)
--------------------------------------------------------------------------------
Sempre nella dashboard Cloudflare (dentro il tunnel "urielscan-msp"):
1) Vai nella tab "Public Hostname" -> "Add a public hostname".
2) Compila:
   - Subdomain: urielscan
   - Domain:    urielsec.com   (risultato: https://urielscan.urielsec.com)
   - Service Type: HTTP
   - URL:          127.0.0.1:8000
3) Salva. Cloudflare crea automaticamente il record DNS CNAME e il certificato
   HTTPS pubblico.

7. HARDENING CONSIGLIATO (VLAN + CLOUDFLARE ACCESS)
--------------------------------------------------------------------------------
A) Firewall su Ubuntu (UFW) e sulla VLAN:
   - Blocca tutto il traffico in ingresso verso il server (lascia eventuale SSH
     solo dalla tua subnet di management interna).
   - Consenti in uscita verso Internet solo:
     * 443/tcp (HTTPS per cloudflared e aggiornamenti)
     * 7844/udp e 7844/tcp (protocollo QUIC/HTTP2 di cloudflared)
     * 53 (DNS) e 123/udp (NTP)

B) Protezione 2FA su UrielScan:
   - Al primo accesso su https://urielscan.urielsec.com cambia la password di
     default di "admin" e attiva subito il 2FA TOTP da Impostazioni -> Sicurezza.

C) Cloudflare Access (Opzionale, incluso nel piano Free):
   - In Zero Trust -> Access -> Applications puoi proteggere la web UI
     richiedendo un codice OTP via email aziendale prima ancora di mostrare
     la pagina di login di UrielScan.
   - IMPORTANTE: se attivi Cloudflare Access sul dominio, aggiungi una policy di
     tipo "Bypass" (Everyone) limitata al path:
       urielscan.urielsec.com/api/agent/*
     In questo modo le sonde remote dei clienti (che usano X-Agent-Token)
     non vengono bloccate dalla pagina OTP del browser.

8. AVVIO DI UNA SONDA REMOTA PRESSO UN CLIENTE
--------------------------------------------------------------------------------
1) Accedi a https://urielscan.urielsec.com -> Settings -> Remote Probes.
2) Seleziona l'organizzazione del cliente, registra la sonda e copia il token.
3) Scarica urielscan_probe.py e avvialo su una macchina nella LAN del cliente:
     python3 urielscan_probe.py --server https://urielscan.urielsec.com --token <TOKEN>

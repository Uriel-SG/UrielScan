          MULTI-TENANT MSP ARCHITECTURE
          
Scan Client LANs Without Opening Firewall Ports.

          
Deploy a single lightweight probe inside each client network. Outbound HTTPS pull eliminates VPN routing headaches and RFC1918 IP conflicts.

        


        

          

            
CLIENT LAN (e.g. 192.168.1.0/24)

            
urielscan_probe.py

            
Runs Nmap, Nuclei & Native scans locally inside the customer's VLAN.

          DEPLOYMENT
          
Up and Running in Seconds.

          
Clone from GitHub, install Python dependencies, and launch UrielScan on Windows or Linux.

        


        

          

            

              1. Central Server (Windows / Linux)
              
            

            
git clone https://github.com/Uriel-SG/UrielScan.git
cd UrielScan
pip install -r requirements.txt
python run.py

          


          

            

              2. Client Remote Probe (Optional)
              
            

            
# Zero external Python dependencies
python3 urielscan_probe.py \
  --server https://urielscan.urielsec.com \
  --token <AGENT_TOKEN>
